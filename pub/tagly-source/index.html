Tagly — source code

Full project: Telegram + Discord bots, the Pollar web app, shared Stellar engine, Groq agent. No secrets included.

⬇ Download .tar.gz ⬇ git bundle

Push it to your GitHub

tar -xzf tagly-source.tar.gz
cd tagly-submission
git remote add origin https://github.com/<you>/tagly.git
git branch -M main
git push -u origin main

Or from the bundle: git clone tagly.bundle tagly && cd tagly then add your remote and push.
